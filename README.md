# PokeTranslator GBA ⚪🔴

**海外ポケモンGBA ROMハック用 日本語化＆翻訳スタジオ**  
*M1/M2/M3 Mac (Apple Silicon) 完全対応・Python標準ライブラリのみで動作（追加インストール不要）*

---

## 📖 概要

**PokeTranslator GBA** は、海外で制作されたゲームボーイアドバンス（GBA）のポケモンROMハック（『Pokémon Radical Red』『Pokémon Unbound』『Pokémon Inclement Emerald』など）を読み込み、ゲーム内の**メニュー、技名、アイテム名、特性、タイプ、セリフ**を日本語に翻訳し、日本語フォントを注入した完成版GBAファイル（またはIPSパッチ）を出力できる翻訳開発ツールです。

### 💡 海外ROMハック日本語化の最大の壁「フォント問題」を解決
従来の英語ROMハックは英語用のASCIIフォントしか持たないため、日本語テキストを書き込むと文字化けを起こすかフリーズしてしまっていました。  
本ツールは、**8x12ピクセルの日本語カナフォント（2bpp）をROM内のフォントグラフィック領域に直接自動注入し、文字幅テーブル（Font Widths Table）を自動更新**します。これにより、パッチ適用後のROMをそのまま **mGBA** や **OpenEmu**、実機（Analogue Pocketなど）で起動するだけで、美しい日本語がネイティブに表示されます。

---

## ✨ 主な機能

1. **🌐 直感的なWeb Studio UI（ブラウザで操作）**
   - `python3 run.py` を実行するだけでSafariやChrome等のブラウザが開き、ドラッグ＆ドロップでROMを読み込めます。
   - 区分別タブ（ポケモン、わざ、どうぐ、とくせい、タイプ、メニュー、セリフ）で整理。
   - インライン編集＆リアルタイム自動保存。

2. **⚡ 第1〜9世代 公式辞書を完全内蔵（一括自動翻訳）**
   - 1,000体以上のポケモン名、900以上の技、全アイテム、全特性、タイプ、性格、戦闘コマンド（たたかう・にげる・バッグ等）を公式日本語名に一撃で自動変換。

3. **📊 リアルタイム進捗＆見込み残り時間（ETA）可視化**
   - 「100%全自動翻訳」「ROMアップロード」「サンプルROM読み込み」「日本語版GBA/IPSパッチ出力」の全主要処理で動的な進捗モーダルを表示。
   - **処理項目数**（`1,848 / 2,357 項目` や `16.0 / 32.0 MB`）、**経過時間**（`00:04`）、**見込み残り時間 (ETA)**（`残り約 2秒`）、**処理速度**（`580 項目/秒` や `45.2 MB/秒`）をリアルタイムに算出・表示します。

4. **🎮 GBA実機テキストプレビュー**
   - 240×160のGBAテキストウィンドウをブラウザ上に忠実に再現。
   - 翻訳した日本語がテキスト枠内にきれいに収まっているかをリアルタイムに確認できます。

5. **🔤 日本語カナフォント自動注入（Font Patcher）**
   - カタカナ・ひらがな・濁点・半濁点・促音・拗音・記号（ー、「」、・など）のビットマップをROMに書き込み。
   - 1文字1バイトの互換枠を活用するため、CFRUなどの高度なスクリプトエンジンを破壊することなく安全に動作します。

6. **🛡️ 32MB自動拡張＆ポインタ自動再配置（Repointing）**
   - 翻訳テキストが元の英語より長くなった場合、ROMを最大32MBまで自動拡張して空き領域に配置し、ROM内の全参照ポインタを自動で再計算・書き換えます。
   - GBAヘッダーチェックサム（0xBD）もGBATEK仕様に従って自動修復するため、起動時のフリーズを防止します。

7. **📦 完成版GBA ＆ IPSパッチ出力**
   - 翻訳済み `.gba` ファイルを即座にダウンロード可能。
   - 配布に便利な差分 `.ips` パッチもワンクリックで生成できます。

8. **💻 コマンドライン（CLI）対応**
   - スクリプト連携や自動化に便利なCLIコマンド（`info`, `extract`, `translate`, `build`, `test-samples`）を完備。

## 🔍 なぜ初期の翻訳率が低かったのか？＆解決した技術的改善

1. **Title Case（頭文字のみ大文字）とハイフン等の正規化の未対応**:
   - 海外ROMハック（Gaia, Unboundなど）では `Headbutt`、`Sand-Attack`、`Bulbasaur` などの表記ゆれが多く、大文字完全一致辞書ではマッチしませんでした。
   - 解決策: `normalize_key()` による英数抽出・大文字統一・ハイフン除去・異体字（`é`、`’`、`ヒ` など）の正規化を導入し、表記ゆれを完全吸収しました。
2. **第4〜9世代ポケモン・メガストーン・新技の網羅**:
   - クチートナイト（Mawilite）等のメガストーン（48種）、TM01〜100、わざレコード、Zクリスタル、ミント、最新の第9世代までの全1,025体のポケモン・850以上の技・270特性を完備。
   - `Charizite X`、`Blastoisite` 等のGBA12文字制限による略称も完全サポート。
3. **どうぐ説明文・セリフの自動翻訳フォールバック**:
   - どうぐ説明文を道具名から自動割り当てするインテリジェント辞書を構築。
   - 自然機械翻訳（Google Translate無料APIによる自動フォールバック機能＋GBA制御タグ `[PLAYER]` `[RIVAL]` `\n` 保護機構）を内蔵し、手作業での修正を極力ゼロに抑えました。
4. **テーブル境界の自動検出**:
   - 従来の固定スキャンで発生していた「技テーブル末尾をはみ出してプログラム領域をガラクタ文字列として読み込んでしまう問題」を名前バリデーションによって解消し、不要な未翻訳項目を排除しました。

## 🖥️ コマンドライン（CLI）の使い方

ターミナルから直接スクリプトやバッチ処理を行うことも可能です。

### ROM情報の解析
```bash
python3 run.py info "Radical_Red_v4.1.gba"
```

### テキストの抽出（プロジェクトファイルまたはCSVへの書き出し）
```bash
python3 run.py extract "Radical_Red_v4.1.gba" -o "radical_red_project.json" --csv
```

### プロジェクトの自動翻訳
```bash
python3 run.py translate "radical_red_project.json"
```

### 日本語化GBA ROMのビルド（フォント注入＋ポインタ再配置）
```bash
python3 run.py build "Radical_Red_v4.1.gba" -p "radical_red_project.json" -o "Radical_Red_JP.gba" --patch-font --ips "Radical_Red_JP.ips"
```

## 🔧 技術的詳細（ROMハックの仕組み）

- **フォント注入の仕組み**:
  - `0x1F3100`（標準フォント）、`0x1FF300`（黒テキスト）、`0x20F618`（青フォント）、`0x21F930`（赤フォント）に、2bpp（16x16 / 4タイル構成）のドット文字データを書き込みます。
  - 同時にフォント幅テーブル（`0x1FB100`, `0x207300`, `0x217618` 等）を各文字のピクセル幅（通常9px、促音・拗音などは6px）に更新するため、文字が詰まったり重なったりしません。
- **ポインタ再配置（Repointing）**:
  - GBAは `0x08000000`〜`0x09FFFFFF` にROMをマッピングします。
  - 元のテキスト長を超える文字列は、拡張されたROM末尾の未使用領域（0xFFブロック）に割り当てられ、ROM全体から参照している4バイトのリトルエンディアンポインタ（例: `0x08XXXXXX`）をすべて自動探索して書き換えます。
- **ヘッダーチェックサム**:
  - GBAは `0xA0`〜`0xBC` のバイト列から計算されるチェックサムが `0xBD` と一致しないと起動時にエミュレータや実機で停止することがあります。本ツールは書き出し時にGBATEK規格に従い自動再計算します。
